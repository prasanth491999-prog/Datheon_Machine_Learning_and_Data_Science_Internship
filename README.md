📌 Internship Projects

✅ Task 1 – Iris Flower Classification

Project Type: Supervised Machine Learning – Classification

Objective: Develop Machine Learning models to classify Iris flowers into three different species.

Dataset: Iris Flower Dataset

Target Classes:

- Setosa
- Versicolor
- Virginica

Work Completed:

1. Dataset loading and exploration.
2. Data inspection and preprocessing.
3. Exploratory Data Analysis (EDA).
4. Data visualization.
5. Correlation heatmap analysis.
6. Training and testing data splitting.
7. Feature scaling.
8. Logistic Regression model development.
9. Decision Tree model development.
10. Model evaluation and comparison.
11. Confusion matrix analysis.
12. Classification report generation.

Machine Learning Algorithms:

- Logistic Regression
- Decision Tree Classifier

Reported Model Results:

Model| Test Accuracy
Logistic Regression| 93.33%
Decision Tree| 93.33%

Results are based on the current project implementation and test split.

Project Documentation: "View Task 1 – Iris Flower Classification" (Task_1_Classification/README.md)

Jupyter Notebook: "View Classification Notebook" (Task_1_Classification/Notebook/classification_pipeline.ipynb)
