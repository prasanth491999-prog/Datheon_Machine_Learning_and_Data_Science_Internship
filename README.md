## 📌 Internship Tasks

### ✅ Task 1: Iris Flower Classification

**Objective:** Build Machine Learning models to classify Iris flowers into three species:

- Setosa
- Versicolor
- Virginica

**Work Completed:**
- Loaded and explored the Iris dataset.
- Performed data inspection and preprocessing.
- Conducted Exploratory Data Analysis (EDA).
- Created visualizations, including a correlation heatmap.
- Split the dataset into training and testing sets.
- Applied feature scaling where appropriate.
- Built Logistic Regression and Decision Tree classifiers.
- Evaluated model performance using accuracy, precision, recall, F1-score, and confusion matrices.
- Compared the performance of both models.

**Models Used:**
- Logistic Regression
- Decision Tree Classifier

**Reported Results:**

| Model | Test Accuracy |
|---|---:|
| Logistic Regression | 93.33% |
| Decision Tree | 93.33% |

*These are the results reported for the current project; they depend on the train-test split and notebook implementation.*

## ⚙️ How to Run the Projects

1. Clone this repository:

```bash
git clone https://github.com/futuristicchakri3/Datheon_Machine_Learning_and_Data_Science_Internship.git
```

2. Navigate to the project directory:

```bash
cd Datheon_Machine_Learning_and_Data_Science_Internship/Task_1_Classification
```

3. Install the required libraries:

```bash
pip install -r requirements.txt
```

4. Launch Jupyter Notebook:

```bash
jupyter notebook
```

5. Open `Notebook/classification_pipeline.ipynb` and run the cells.
